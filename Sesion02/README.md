# Práctica de CSS 

Proyecto organizado en seis experiencias independientes. 

## Contenido

- Experiencia 01: formas de aplicar CSS.
- Experiencia 02: selectores básicos.
- Experiencia 03: atributos, pseudoclases y pseudoelementos.
- Experiencia 04: combinadores, grupos, atributos patrón, herencia y cascada.
- Experiencia 05: medidas absolutas y relativas.
- Experiencia 06: modelos de color y opacidad.
